# Arundo Analytics

> Arundo Analytics is an industrial AI company with offices in Oslo, Stockholm, Heidelberg and Houston, building software for asset-heavy industries — oil and gas, maritime and shipping, chemicals and manufacturing. Its Arundo AI Foundation platform combines a knowledge graph of asset hierarchies and sensor metadata, industrial time-series storage for high-velocity sensor data, parallelised machine-learning model orchestration, and specialised AI agents, surfaced through the AI Foundation Studio and what the company calls the Arundo Foundation APIs.

This file was generated by API Evangelist from public sources on 2026-08-06. Arundo does not publish an llms.txt of its own (https://www.arundo.com/llms.txt returns 404).

## Important: API availability

Arundo markets "Arundo Foundation APIs" on its technology page, but as of 2026-08-06 there is **no public developer program**: no developer portal, no API reference, no getting-started guide, no OpenAPI/AsyncAPI/GraphQL specification, no MCP server and no A2A agent card. Customer applications (CarbonPath, Marathon) sit behind an Auth0 login. Do not attempt to call a Foundation API from a public specification — none is published.

## Products

- [Arundo AI Foundation](https://www.arundo.com/technology): AI agents, knowledge graph, model orchestration, industrial data storage, and APIs/applications.
- [AI Companion](https://www.arundo.com/ai-companion): assistant for industrial productivity and innovation workflows.
- [Marathon](https://www.arundo.com/marathon): continuous condition monitoring for critical equipment.
- [ArundoEdge and Edge Manager](https://www.arundo.com/arundo-edge): secure streaming of IoT sensor data from control systems to the cloud.
- [Energy Optimizer](https://www.arundo.com/energy-optimizer): mathematical optimization plus machine-learned electricity price forecasts.
- [CarbonPath](https://www.arundo.com/carbonpath): Scope 3 emissions management for shipping.

## Machine-readable surface

- [Foundation compute plug-in contract](https://github.com/arundo/foundation-compute-example/blob/main/API_SCHEMA.md): request/response specification for a Foundation compatible compute (POST /execute/{compute_name}, GET /healthz), implemented by the third party, not hosted by Arundo.
- [JSON Schema (derived)](https://raw.githubusercontent.com/api-evangelist/arundo-analytics/refs/heads/main/json-schema/arundo-analytics-foundation-compute.json): the above contract expressed as JSON Schema 2020-12 by API Evangelist.
- [OpenID Connect discovery](https://arundo.eu.auth0.com/.well-known/openid-configuration): the Auth0 EU tenant that authenticates Arundo customer applications.
- [Status API](https://status.arundo.com/api/v2/summary.json): Atlassian Statuspage component status for Marathon, BOP Counter, Edge Manager, DW Production Recommender, ECU Load Optimization, CarbonPath and AI Companion.
